# 用户体验研究作品集

目标地址：https://guoy418.github.io/UX/

静态网站，访客无需登录。GitHub Pages 发布源为 main 分支的 /docs 目录。

- docs/index.html：页面外壳；修改后同步到 docs/projects/*/index.html
- docs/content.js：项目列表和人群数据
- docs/content/lloyds.js：Lloyds 项目正文
- docs/app.js：渲染与交互
- docs/styles.css：响应式视觉系统
- docs/assets/lloyds：已选择的展示图片

所有页面与资源已适配 /UX/ 子路径。原始 Word、PDF、Sites 身份及登录凭据均不在此仓库。

个人履历、项目角色/时间和其他案例仍待补充。详细内容组织说明见 SOURCE-NOTES.md（描述的是原 Sites 版本，GitHub 版本使用 docs 代替 dist）。
